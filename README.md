# 宋家乐个人作品集

基于 React + Vite 的视觉设计 / AI 设计 / 品牌设计个人作品集，整体采用暗色、克制、科技感的视觉方向。

## 本地运行

```bash
pnpm install
pnpm dev
```

打开终端显示的本地地址即可预览。

## 主要模块

- 全屏视频 Hero 与导航
- 个人介绍、联系方式、经历与项目数据
- 游戏广告：球形叠加拖拽画廊与 6 条视频案例
- AI 漫剧：《炼气 3000 层》《大夏镇妖录》
- 获奖作品：《醒狮入梦》完整个人创作案例
- 能力优势与整屏联系收尾页

## 部署

推送至 `main` 分支后，GitHub Actions 会自动构建并发布到 GitHub Pages。
